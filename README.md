# 👟 Shoe Order Automation System

A fully automated shoe order processing system built using Google Forms, Google Sheets, Make.com, Slack, and email automation. Automates customer order intake, notifications, and fulfillment coordination without manual intervention.

---

## 📌 Overview

This system automates the entire order lifecycle for a shoe business:
- Customers place orders via Google Forms
- Orders are automatically stored in Google Sheets
- Customers receive instant confirmation emails
- The fulfillment team is notified via Slack
- Orders are tracked with status updates

---

## 🧩 Problem Statement

Small businesses often rely on manual workflows to manage orders:
- Copying form submissions into spreadsheets  
- Sending confirmation emails manually  
- Notifying teams through chat apps  

This leads to delays, errors, and inefficient operations.

---

## 🚀 Solution Overview

This system automates the entire workflow:

1. Customer submits order via Google Forms  
2. Data is stored in Google Sheets  
3. Make.com triggers automation workflow  
4. Customer receives confirmation email  
5. Fulfillment team gets Slack notification  
6. Order is tracked centrally

---

## ⚙️ Setup Instructions

1. Create a Google Form for order collection  
2. Link form responses to Google Sheets  
3. Set up a Make.com scenario trigger (Google Sheets watch rows)  
4. Configure:
   - Email module (customer confirmation)
   - Slack module (team notification)
5. Test with a sample order submission
